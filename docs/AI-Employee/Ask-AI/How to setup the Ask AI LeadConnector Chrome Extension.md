The Ask AI LeadConnector Chrome Extension allows Ask AI to open webpages, click, type, scroll, and complete supported browser tasks for you.

  


You can install it by entering a browser-based request in Ask AI and selecting **Install** when prompted, or by opening the link directly: [LeadConnector – Ask AI listing in the Chrome Web Store](<https://chromewebstore.google.com/detail/leadconnector-ask-ai/idbhohjlbibgnelhchaakcpdjkodggpl>) ([](<https://chromewebstore.google.com/detail/leadconnector-ask-ai/idbhohjlbibgnelhchaakcpdjkodggpl>)<https://chromewebstore.google.com/detail/leadconnector-ask-ai/idbhohjlbibgnelhchaakcpdjkodggpl>).

# **How to Install the Ask AI LeadConnector Chrome Extension**

  


You can install the AI LeadConnector directly from this link: [](<https://chromewebstore.google.com/detail/leadconnector-ask-ai/idbhohjlbibgnelhchaakcpdjkodggpl>)[LeadConnector – Ask AI listing in the Chrome Web Store](<https://chromewebstore.google.com/detail/leadconnector-ask-ai/idbhohjlbibgnelhchaakcpdjkodggpl>) or by following the steps below.

  


  1. Navigate to**Ask AI** from the left menu.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076734216/original/ElsRnREAoOPQAfEZ0tc9BbYwabWodIHdAg.png?1784844635)  
  

  2. Enter a request that requires browser interaction.  
  
_Example: "Open Google Docs and create an event landing page outline."_  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076734319/original/_lV-VWRzUKewUmkuuMYPz9DJnOtcQJDY3g.png?1784844929)  
  

  3. Select **Install** when Ask AI prompts you to install the browser extension. You will be redirected to the **[LeadConnector – Ask AI](<https://chromewebstore.google.com/detail/leadconnector-ask-ai/idbhohjlbibgnelhchaakcpdjkodggpl>)** listing in the Chrome Web Store.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076734321/original/BB_uwkwQnahpTR-L_Ggf46ER-929MIZVOg.png?1784844942)  
  

  4. On the Chrome Web Store page, select **Add to Chrome**.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076734324/original/KTudp0XyyH0hfJUFM5Fwxd_1rOvoa6CeIQ.png?1784844953)  
  

  5. Review the extension permissions, then select **Add extension**.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155076734391/original/d5UWdrW0H4eDQlDyygZrbRUFF3Gqlmftgw.png?1784845199)
