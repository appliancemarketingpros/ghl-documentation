# **What is Importing Email Templates with Email AI?**

  


Email AI can convert an existing email into a reusable HighLevel template by reading the email you send to a unique import email address. Once the email is received, HighLevel uses AI to recreate the email structure so you can continue editing it in either the Design Editor or Code Editor.  
  


Import Email Templates with Email AI helps you bring campaigns from tools like Mailchimp, Active Campaign, Kajabi, HubSpot, or another email platform into HighLevel. Instead of manually rebuilding layouts, copying text, and recreating buttons, you can import the original email and start editing the converted version.

* * *

## **Key Benefits of Importing Email Templates with Email AI**

  


  * **Platform flexibility:** Import emails from your inbox or previous marketing platforms without being limited to one provider.  
  


  * **Faster client onboarding:** Bring a client’s existing high-performing emails into HighLevel in minutes.  
  


  * **Less manual rebuilding:** Convert an existing email into an editable template instead of recreating the layout from scratch.  
  


  * **AI-assisted optimization:** Use Email AI to make improvements after the email has been imported.  
  


  * **Reusable campaign assets:** Turn existing emails into templates that can be edited, saved, and used for future campaigns.  
  


  * **Editor choice:** Open the imported template in the Design Editor for visual editing or the Code Editor for HTML-level control.

## **Supported Import Options**

  


The import dropdown helps you choose the source that best matches where the email came from. Selecting the correct option gives HighLevel better context when Email AI converts the email into an editable template.

  


**Available import options include:**

  


  * Import from any platform with AI

  * Mailchimp

  * Active Campaign

  * Kajabi


  


Use **Import from any platform with AI** when the email comes from an inbox, a provider not listed in the dropdown, or a general external source. Use a platform-specific option when the email was created in one of the listed tools.

## **How To Import Email Templates with Email AI**

  


A successful import starts by sending or forwarding the email to the dynamic email address shown in HighLevel. After the email is received, HighLevel can convert it into an editable template so you can review, adjust, and save it for future use.

  

    
    
    **Important:** Email AI can make mistakes. Always review the imported template before using it in a live campaign. Check the layout, images, buttons, links, spacing, copy, personalization, and mobile appearance.
    

  


  1. Go to **Marketing** in the left navigation menu.  
  


  2. Click **Emails** in the top navigation menu.  
  


  3. Open **Templates**.  
  
![](https://jumpshare.com/share/2KznD8JuUKPfHFHNEeiQ+/Screen+Shot+2026-04-29+at+17.13.03.png)  
  


  4. Click + **New**.  
  


  5. Select **Import Email with AI**.  
  
![](https://jumpshare.com/share/D1clLTm2wh9NG53aq1CQ+/Screen+Shot+2026-04-29+at+17.14.43.png)  
  


  6. In the **Import Email Templates** modal, choose where the email is being imported from.  
  


     * Select **Import from any platform with AI** for emails from an inbox or unsupported platform.  
  


     * Select a listed platform, such as **Mailchimp** , **Active Campaign** , or **Kajabi** , when applicable.  
  
![](https://jumpshare.com/share/Iv8H0gTuCCjVayEILnJQ+/Screenshot+2026-04-29+at+16.59.07.png)  
  


  7. **Copy** the **dynamic** **email** **ID** shown under **Send an email to**.  
  


  8. From your **inbox** or **previous** **marketing** **platform** , **send a test email or forward the email to the copied import email address**.  
  
![](https://jumpshare.com/share/yyhbY8e7iB2kVSRqE1BY+/GIF+Recording+2026-04-29+at+17.22.57.gif)  
  


  9. Return to Email Import screen after the email is sent.  
  


  10. Choose whether to open the converted template in the **Design Editor** or **Code Editor**.  
  


  11. Click **Continue**.  
  


  12. Review the imported email and make any needed edits before saving or using it in a campaign.  
  
![](https://jumpshare.com/share/8ESTjpBZph9XjEfUNe40+/GIF+Recording+2026-04-29+at+17.24.56.gif)

## **Design Editor vs. Code Editor**

  


Choosing the right editor determines how you will edit the imported email after Email AI converts it. The Design Editor is best for visual editing, while the Code Editor is best for users who need direct control over the email HTML.  
  


Choose **Open in Design Editor** when you want to:  
  


  * Edit the template visually with drag-and-drop style controls

  * Adjust text, buttons, images, and layout without working in code

  * Make quick marketing updates after importing the email

  * Hand the template off to users who prefer a visual editor  
  


Choose **Open in Code Editor** when you want to:  
  


  * Review or edit the email HTML directly

  * Preserve a code-based workflow for custom layouts

  * Make technical changes that require HTML knowledge

  * Continue working with a template that was originally built as custom HTML

## **Frequently Asked Questions**

  


**Q: What platforms can I import templates from?**  
You can import from any email platform that allows you to send a test email or campaign, including Mailchimp, Klaviyo, ConvertKit, ActiveCampaign, Constant Contact, and more. Use **Import from any platform with AI** when the provider is not listed in the dropdown.

  


**Q: Can I forward an email from my inbox instead of sending a test email from another platform?**  
Yes. You can forward an existing email from your inbox to the dynamic import email address shown in HighLevel.

  


**Q: Will my email’s original formatting and images stay intact?**  
Email AI is designed to preserve the email’s structure, HTML, images, and design elements during import. Always review the converted template before using it in a live campaign, since some elements may need minor adjustments.

  


**Q: Can I use the imported template in campaigns right away?**  
Yes. Once imported, the template can be used in email campaigns or automations after you review, edit, and save it.

  


**Q: What if I update the original template on the other platform?**  
Re-import the updated version by sending or forwarding the updated email to the system-generated import address shown in HighLevel.

  


**Q: Does this work with plain-text emails too?**  
Yes. Plain-text emails can be imported, but the Code Editor is best suited for HTML-based emails with structured content.

  


**Q: Where do imported templates appear in my HighLevel account?**  
Imported templates appear under **Marketing > Emails > Templates**, just like manually created templates.

  


**Q: Should I use the Design Editor or Code Editor?**  
Use the Design Editor if you want to visually edit the email without code. Use the Code Editor if you need direct HTML control or are working with a custom-coded email.

  


**Q: What should I check after importing the template?**  
Review the layout, images, buttons, links, spacing, branding, copy, merge fields, and mobile appearance before saving or sending the email.

  


**Q: Can I import competitor emails or emails I received from another sender?**  
You can forward an email from your inbox to use it as a starting point for a new editable template. Make sure the final template uses your own branding, content, links, and compliant messaging before sending.
