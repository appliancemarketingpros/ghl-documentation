# Multi-Attendee Registration with Individual Details and Data Copying

Capture attendee information for every ticket purchased and speed up group registrations with built-in data copying.

What You'll Learn

HighLevel Events supports collecting individual attendee information for every ticket in a registration. Instead of capturing details only for the primary buyer, you can now collect each attendee's name, email, and event-specific information.

This guide explains how multi-attendee registration works, how to use the data copying feature to speed up group bookings, and how this capability improves the experience for conferences, workshops, corporate events, and team registrations.

## What is Multi-Attendee Registration?

Multi-attendee registration allows you to capture individual attendee information for every ticket purchased in a single transaction. Each attendee can have their own name, email, and event-specific details, rather than only collecting information for the primary buyer.

The primary buyer is automatically treated as the first attendee, and subsequent attendee forms appear for each additional ticket. This capability is designed for conferences, workshops, team registrations, corporate bookings, and any multi-ticket event where individual participant tracking is required.

2

## Key Benefits

Multi-attendee registration with data copying delivers several advantages for both event organizers and attendees.

**Individual Attendee Tracking** — Capture accurate details for every participant, not just the primary buyer, making it easier to manage check-ins, badges, and attendee communications.

**Faster Group Bookings** — Copy attendee information from previously entered attendees within the same registration to eliminate repetitive data entry for team or corporate bookings.

**Flexible Data Editing** — Edit copied information whenever needed to customize details for each attendee while maintaining a fast registration flow.

**Better Attendee Experience** — Reduce friction during checkout while ensuring every participant has their own registration record.

**Event-Specific Fields** — Collect custom information for each attendee, such as dietary preferences, t-shirt sizes, or session selections.

## How Multi-Attendee Registration Works

When a buyer purchases multiple tickets for an event, the registration process automatically collects individual attendee information for each ticket.

Step 1

Primary Buyer Becomes First Attendee

The primary buyer's information (name, email, and any event-specific fields) is automatically used for the first attendee record.

Step 2

Additional Attendee Forms Appear

For each additional ticket, a separate attendee form appears during the registration flow. Each form collects the same information fields (name, email, and custom fields) configured for the event.

Step 3

Complete or Copy Information

The buyer can manually enter each attendee's information or use the data copying feature to reuse information from a previously completed attendee in the same registration.

Step 4

Review and Complete Registration

Once all attendee forms are completed, the buyer proceeds to checkout. Each attendee receives their own registration record with individual details.

Note

The primary buyer's email is used for order confirmation and receipt communication. Each individual attendee receives their own confirmation email with their specific registration details.

## Using the Data Copying Feature

The data copying feature allows buyers to reuse attendee information from any previously completed attendee within the same registration, significantly speeding up group bookings.

Step 1

Select Copy Attendee Information

On any attendee form after the first, locate and select the option to copy attendee information. This option appears once at least one attendee's information has been completed.

Step 2

Choose an Attendee to Copy From

Select which previously entered attendee's information you want to copy. All completed attendees from the current registration appear in the list.

Step 3

Review and Edit Copied Information

The selected attendee's information populates all form fields. You can edit any field to customize the information for the current attendee while keeping the copied data as a starting point.

Pro Tip

For corporate team registrations where many attendees share the same company information or preferences, copy the first attendee's details and update only the name and email fields for each subsequent attendee.

## Best Practices for Group Registrations

Follow these best practices to optimize the multi-attendee registration experience for your events.

Best Practice 1

Minimize Required Fields

Only require essential information for each attendee. Too many required fields increase registration time and abandonment, even with data copying available.

Best Practice 2

Clearly Label Attendee Forms

Each attendee form displays a sequential label (e.g., Attendee 1, Attendee 2). Use clear instructions at the beginning of the registration to explain that each ticket requires individual attendee information.

Best Practice 3

Promote Data Copying for Team Bookings

For events targeting corporate teams or groups, include instructions that highlight the data copying feature to reduce perceived registration complexity.

Best Practice 4

Use Event-Specific Fields Strategically

Add custom fields (dietary preferences, session selections, t-shirt sizes) only when you need individual attendee responses. Generic fields like company name are better copied from the first attendee.

## Frequently Asked Questions

Q: Does every ticket require individual attendee information?

Yes. When a buyer purchases multiple tickets, each ticket requires its own attendee information. The primary buyer is automatically treated as the first attendee, and additional forms appear for each remaining ticket.

Q: Can I copy attendee information from a previous registration or event?

No. The data copying feature only works within the same registration session. You can copy from any previously completed attendee in the current registration, but not from attendees in separate orders or past events.

Q: What happens if I edit copied information?

Editing copied information only affects the current attendee. The original attendee's information remains unchanged, and you can continue to copy from that attendee to other tickets in the same registration.

Q: Can I disable individual attendee collection for my event?

Multi-attendee registration is a standard part of the Events checkout experience for multi-ticket purchases. If your event only requires buyer information, configure your event to limit purchases to one ticket per order.

Q: Do all attendees receive separate confirmation emails?

Yes. Each attendee receives their own confirmation email with their specific registration details. The primary buyer also receives an order confirmation email summarizing all tickets purchased.

Q: Which custom fields can I collect for each attendee?

Any event-specific fields configured in your event settings appear on each attendee form. Common examples include dietary preferences, t-shirt sizes, session selections, or accessibility requirements. Standard fields (name and email) are always collected.

Q: Can I view individual attendee information after registration?

Yes. Individual attendee information is stored with the registration order and can be viewed in the event management dashboard. Each attendee is listed separately with their collected details.

Q: Is there a limit to how many attendees I can copy information from?

No. You can copy information from any attendee who has completed their form within the current registration, regardless of how many tickets are being purchased.
