# **What are Social Planner Notifications?**

  


Social Planner notifications are email alerts that keep users informed about important account and publishing events. They can alert the appropriate users when a social account token is about to expire or has expired, when a post requires approval, or when a scheduled post is approved, rejected, or fails to publish.

  


Social Planner provides six notification types:

  


  * **Account Pre-Expiry:** Notifies selected users before a connected social account token expires.  
  

  * **Account Expired:** Notifies selected users when a connected social account token has expired.  
  

  * **Request for Post Approval:** Notifies the approver when a scheduled post is submitted for approval.  
  

  * **Approved Post:** Notifies the creator when their scheduled post is approved.  
  

  * **Rejected Post:** Notifies the creator when their scheduled post is rejected and includes the rejection comment.  
  

  * **Post Failed:** Notifies selected users when a scheduled post fails to publish and includes the failure reason.

## **Social Planner Notification Types and Settings**

  


Each notification type supports different configuration options. Knowing which settings are available helps you configure each alert for the correct users and purpose.

  


Notification| Enable/Disable| Email Template| Users to Notify| Reminder Frequency  
---|---|---|---|---  
**Account Pre-Expiry**|  Yes| Yes| Yes| Yes  
**Account Expired**|  Yes| Yes| Yes| Yes  
**Request for Post Approval**|  Yes| Yes| No| No  
**Approved Post**|  Yes| Yes| No| No  
**Rejected Post**|  Yes| Yes| No| No  
**Post Failed**|  Yes| Yes| Yes| No

## **How to Set Up Social Planner Notifications**

  


Properly configuring notifications ensures that the appropriate users receive email alerts for the account and publishing events they need to monitor. Notification settings are managed directly from Social Planner.

  


  1. Go to **Marketing > Social Planner**.  
  

  2. Make sure the required social accounts are connected.  
  
![](https://jumpshare.com/share/AsRJDf1vTG6td7vfn7kS+/Screen+Shot+2026-08-31+at+18.28.12.png)  
  

  3. Click **Settings**.  
![](https://jumpshare.com/share/31PgJxaLXeo9Bv4Nwrdj+/Screen+Shot+2026-08-31+at+19.31.02.png)  
  

  4. Select **Notifications** from the left menu.  
  


  5. Locate the notification you want to configure.  
  

  6. Use the **Status** **toggle** to turn on/off the notifications.  
  

  7. Click the **pencil icon** in the Action column to configure its available settings.  
  

  8. Configure the options available for that notification.  
  

  9. Click **Save Changes**.  
  
![](https://jumpshare.com/share/nSHIw3sZM6pHgXgXSV0r+/GIF+Recording+2026-08-31+at+19.40.05.gif)

### **Configure Account Pre-Expiry Notifications**

  


Account Pre-Expiry notifications provide additional controls so you can determine who should receive advance alerts and how frequently they should be reminded.

  


  1. Turn on **Account Pre-Expiry**.  
  

  2. Open its configuration using the **pencil icon**.  
  

  3. Under the users to notify option, click the **+** button and select the users who should receive the email.  
  

  4. Select the **frequency of the reminders** for the selected users.  
  

  5. **Select** the **email** **template** you want to use. The default template is selected automatically, but you can choose an existing custom email template.  
  

  6. Click **Save Changes**.  
  
![](https://jumpshare.com/share/WvbMICKunBs5bGixOHhF+/GIF+Recording+2026-08-31+at+19.42.12.gif)


* * *

### **Configure Account Expired Notifications**

  


Account Expired notifications offer recipient and reminder controls so the appropriate users can continue receiving alerts about an expired connection.

  


  1. Turn on **Account Expired**.  
  

  2. Open its configuration using the **pencil icon**.  
  

  3. **Select** the **users** **who** **should** **receive** the **notification**.  
  

  4. **Select** the **reminder** **frequency**.  
  

  5. **Select** the **email** **template**.  
  

  6. Click **Save Changes**.  
  
![](https://jumpshare.com/share/SriABv31M4BLXOVRg0zg+/GIF+Recording+2026-08-31+at+19.48.39.gif)

### **Configure Post Approval Notifications**

  


Request for Post Approval, Approved Post, and Rejected Post notifications use predefined recipients based on the approval workflow. Their notification settings allow you to control the status and email template rather than manually selecting recipients or reminder frequencies.

  


For each notification:  
  


  1. Turn on the notification using the **Status** toggle.  
  

  2. Click the **pencil icon**.  
  

  3. Select the email template you want to use.  
  

  4. Click **Save Changes**.  
  


**Repeat these steps as needed for:  
**  


  * Request for Post Approval
  * Approved Post
  * Rejected Post


  


![](https://jumpshare.com/share/MASeSa0gRVy7Q8BRQCe9+/GIF+Recording+2026-08-31+at+19.50.22.gif)

### **Configure Post Failed Notifications**

  


Post Failed notifications can be sent to selected users when a scheduled post cannot be published. Selecting the appropriate recipients helps ensure publishing failures are seen by users who can review them.

  


  1. Turn on **Post Failed**.  
  

  2. Click the **pencil icon**.  
  

  3. **Select** the **users** **who** **should** **be** **notified** by **email** when a post fails to publish.  
  

  4. **Select** the **email** **template**.  
  

  5. Click **Save Changes**.

## **Frequently Asked Questions**

  


**Q: How does Pre-expiry notification work?**

The token for Facebook expires every 90 days. Before the 10 days of expiry (i.e 80th day), we will be sending pre-expiry notification to the selected users. They can manage the frequency of notification to be sent every 1-10 days.

  


**The blank preview you’re seeing for the Default Template is expected behavior.**  
Here’s why:

  * Where are the Default Templates stored?


These are built-in system templates managed by the platform. They are not stored within the location’s Email Templates library, which is why you won’t find them when searching there.

  


  * Can the Default Templates be viewed or edited?


No. Since they are system-level templates, they cannot be viewed or edited directly.

  


  * Is the blank preview a bug?


No. The preview attempts to load the selected template from the location’s Email Templates library. Because the Default Template exists only at the system level and not within the location, there is no template available for the preview to display, resulting in a blank preview. This is a current product limitation rather than a bug. The notification emails will still be sent with the correct default content.
