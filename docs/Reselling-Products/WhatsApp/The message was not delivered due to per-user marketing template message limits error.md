# "Per-User Marketing Template Message Limits" Error

Why this error appears and what to expect

I am facing an error. The message was not delivered due to a per-user marketing template message limits error.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155043380330/original/chCN0Ga4xJ3Yl4YqfZs47KtdziTW6BVUIA.png?1742194317)

* * *

## Solution

This error occurs because the phone number has received the maximum number of marketing messages from other business platforms as well — this is to be expected.
    
    
    The error lasts for 24 hours, after which it disappears, allowing you to send utility templates.
