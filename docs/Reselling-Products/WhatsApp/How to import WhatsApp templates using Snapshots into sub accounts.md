# Import WhatsApp Templates Using Snapshots

Copy WhatsApp templates and other assets between sub-accounts quickly and consistently

Table of Contents

  * • How to Import WhatsApp Templates Using Snapshots
  * • FAQs


    
    
    Prerequisites
    
    Before using Snapshots for WhatsApp templates, please ensure the following:
    
    • You have an active CRM subscription, as Snapshots are only available to active accounts.
    • The sub-account has WhatsApp properly integrated. Templates cannot be loaded or used unless WhatsApp is already connected.
    
    Once both requirements are met, you can use Snapshots to load and transfer WhatsApp templates into your sub-accounts successfully.

  * Navigate to **Account Snapshots**.

## FAQs

Q1. What are the prerequisites before using Snapshots?

Before using Snapshots to load WhatsApp templates, make sure:

  * You have an active CRM subscription.
  * The target sub-account has WhatsApp integrated.


Once both are in place, you can create and apply Snapshots to transfer WhatsApp templates into sub-accounts.

Q2. What is a Snapshot in the CRM?

A Snapshot is a saved template that allows agencies to copy workflows, templates, settings, and automations from one sub-account to another.

Q3. Why should I use Snapshots to import WhatsApp templates?

Using Snapshots helps save time and ensure consistency across multiple sub-accounts by transferring pre-configured WhatsApp templates and other assets.

Q4. How do I create a Snapshot for WhatsApp templates?

  * Log in to Agency Dashboard > go to Account Snapshots > click Create New Snapshot.
  * Enter a Snapshot Name and select the sub-account to copy templates from.
  * Click Next and select the assets you want to include.
  * Click Create to finalize the Snapshot.


Q5. How do I apply a Snapshot to a sub-account?

  * Navigate to Sub-Accounts in the Agency Dashboard.
  * Select the sub-account where you want to import the Snapshot.
  * Click the three dots and select Manage Client.
  * Click Actions > select Load Snapshot.


Q6. How do I import WhatsApp templates using the Snapshot?

  * Select the Snapshot Name from the list and click Proceed.
  * Choose the assets (templates, workflows, etc.) that need to be transferred.
  * Click Proceed to continue the import process.


Q7. What happens after the import is completed?

  * The system will automatically transfer all selected assets into the sub-account.
  * Once the process is completed, click OK to confirm.
  * All imported templates will be submitted to Meta for approval before they can be used.


Q8. What should I do if the WhatsApp templates are not appearing in the sub-account?

  * Double-check that the correct Snapshot was selected during the import process.
  * Ensure that all necessary assets were selected before proceeding.
  * Refresh the sub-account and check under Automations > Templates.


Q9. Can I edit a Snapshot after it has been created?

No, Snapshots cannot be edited after creation. If changes are needed, you must create a new Snapshot and apply it again.

Q10. Can I apply the same Snapshot to multiple sub-accounts?

Yes, you can reuse the same Snapshot and apply it to multiple sub-accounts for easy replication.
