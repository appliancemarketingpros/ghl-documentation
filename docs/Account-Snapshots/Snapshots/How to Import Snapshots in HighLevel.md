How to Import Snapshots in HighLevel

Import shared Snapshots into your HighLevel agency library so you can review and reuse supported assets across sub-accounts. The redesigned import flow lets you rename a Snapshot, track processing, and understand share-link errors more easily. Protected assets remain available for internal use after import while retaining their protection at the agency boundary.

What You'll Learn

This guide explains how Snapshot importing differs from loading, how to import from a share link or email invitation, how to monitor processing and troubleshoot failed imports, and what happens when the imported Snapshot contains protected assets.

Important

**Importing and loading are different actions.** Importing adds the shared Snapshot to your agency-level Snapshot library. Loading applies selected assets from that Snapshot to a specific sub-account.

# What is Snapshot Import?

Snapshot import is the process of adding a shared Snapshot to your HighLevel agency using a Snapshot Share Link or email invitation. Once imported, the Snapshot is stored in your agency-level Snapshot library, where you can review it before applying its assets to a sub-account.

Importing does not automatically place Snapshot assets inside a client account. To apply those assets, you load the imported Snapshot into the intended sub-account and choose which supported assets to include.

**Simple workflow:** Share → Import into the agency library → Load into a sub-account.

2

## Key Benefits of Snapshot Import

The redesigned import experience gives agencies clearer control from the moment a shared Snapshot is opened until it becomes ready for use. Better naming, status visibility, error guidance, and protection indicators make imports easier to manage.

**Better Organization:** Rename a Snapshot during import so it is easier to identify in your agency library.

**Faster Setup:** Start from a valid Snapshot Share Link or email invitation and add the Snapshot directly to your agency library.

**Clear Import Visibility:** See a greyed-out state while the Snapshot is processing and know when it becomes ready to use.

**Helpful Error Guidance:** Identify expired, used, restricted, or unavailable share links more quickly.

**Asset Protection Visibility:** Use the shield indicator to recognize Snapshots containing protected assets while retaining access to those assets for internal use.

**Reusable Internal Workflows:** After a protected Snapshot is legitimately imported, protected assets can be reused across sub-accounts and internal Snapshot workflows in the same agency.

3

## Importing Assets Protected Snapshots

Assets Protection allows Snapshot creators to restrict external redistribution without preventing legitimate use inside the receiving agency. Importing an Assets Protected Snapshot does not remove its protection, but it also does not prevent you from using protected assets throughout your own agency.

Action| Protected Asset Behavior  
---|---  
Import a valid protected Snapshot| **Allowed**  
Load protected assets into a sub-account in the receiving agency| **Allowed**  
Reuse protected assets across other sub-accounts in the same agency| **Allowed**  
Create or refresh another Snapshot using protected assets| **Allowed within the agency**  
Share or resell protected assets to another agency| **Restricted**  
Externally share a mixed Snapshot| Eligible non-protected assets can continue; protected assets are excluded.  
  
**Protection stays attached:** Loading, copying, or reusing a protected asset within your agency does not remove or weaken its protected status.

## Tracking Snapshot Import Progress

Import status helps you distinguish a Snapshot that is still processing from one that is ready to use. Waiting for processing to finish prevents duplicate import attempts and avoids trying to load an incomplete Snapshot.

  * After the import begins, the Snapshot appears in your imported Snapshots list.
  * The Snapshot appears **greyed out** while processing is still underway.
  * You do not need to start another import because the Snapshot is greyed out.
  * When processing finishes, the Snapshot becomes active and ready to use.


**Tip:** Wait until the Snapshot becomes active before attempting to load it into a sub-account.

## Understanding Snapshot Import Errors

Share links can fail for different reasons, and the correct next step depends on whether the link expired, was already used, is restricted to another destination, or points to an unavailable Snapshot. Identifying the reason first helps avoid unnecessary retries.

Scenario| What It Means| What To Do  
---|---|---  
**Expired Snapshot Share Link**|  The shared link is no longer valid.| Ask the Snapshot owner to generate a new share link.  
**One-Time Link Already Used**|  The permitted import has already been completed.| Ask the sender to generate another one-time link.  
**Restricted Link**|  The link may be limited to a particular agency or sub-account.| Confirm that you are signed in to the intended agency and that the sender used the correct restriction.  
**Unavailable Snapshot**|  The source Snapshot may no longer exist or be available through that share.| Ask the sender to verify the Snapshot and generate a valid share if needed.  
**General Import Failure**|  The import did not complete successfully.| Retry after confirming the share is still valid. Contact support if the problem continues.  
**Shield / Assets Protected Indicator**|  The Snapshot contains protected assets.| **No error.** Continue with the valid import. Protection remains attached to the applicable assets.

## How To Import a Snapshot

Importing the Snapshot first ensures it is stored in the correct agency library before you attempt to use its assets in a sub-account. You can begin from either a Snapshot Share Link or an email invitation.

Required Access

If you cannot import a Snapshot, verify that your user has the appropriate Snapshot permissions, including **Share/Import Snapshots**.

Method 1

### Import a Snapshot from a Snapshot Share Link

A Snapshot Share Link opens the recipient import experience directly. Sign in to the agency where you want the Snapshot stored before opening the link.

  1. Sign in to the HighLevel agency where you want to import the Snapshot.
  2. Open the **Snapshot Share Link** provided by the sender. You can paste it into a new browser tab if needed.
  3. Review the Snapshot import pop-up.
  4. Enter a custom Snapshot name if you want to rename it before importing.
  5. Click **Import Now**.
  6. Watch for the Snapshot to appear in your imported Snapshots list.
  7. Wait until the greyed-out processing state clears and the Snapshot becomes available.


![Snapshot import pop-up with Snapshot naming and Import Now controls](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071794433/original/_TcGehhSTyMP6Ce-mnS7Gm1xlFcvh810Cg.png?1779279980)

![Imported Snapshots list showing a Snapshot in the greyed-out processing state](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071794510/original/Z9STIZhBAXLpIBgqwIVB63VfusmnL5cfJA.png?1779280031)

Method 2

### Import a Snapshot from Email

An email invitation launches the same general import experience while delivering access directly to the intended recipient.

  1. Sign in to the HighLevel agency where the Snapshot should be imported.
  2. Open the Snapshot invitation email.
  3. Click the Snapshot import link in the email.
  4. Review the Snapshot import pop-up.
  5. Rename the Snapshot if needed.
  6. Click **Import**.
  7. Wait for processing to finish before loading the Snapshot into a sub-account.

## Load the Imported Snapshot Into a Sub-Account

An imported Snapshot remains at the agency level until you deliberately load it into a sub-account. Loading gives you control over the destination, selected assets, and any conflicts with assets that already exist in the sub-account.

**Protected assets can be loaded internally:** If the imported Snapshot contains protected assets, those assets can be selected and loaded into sub-accounts within the same agency. Loading them does not remove their protection.

Step 1

Open the Destination Sub-Account

From **Agency View** , locate the sub-account where you want to load the Snapshot. Open the sub-account action menu and select **Manage Client**.

![Agency sub-account list showing the action menu for the destination sub-account](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080791240/original/ZH-0zrpdbvaNafkINQVtWru29MUT0ktZeg.png?1789246310)

![Sub-account action menu showing Manage Client](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071796844/original/s8mSERi6DDizLkg3Bb_c9X-67e3Oy6jFuA.png?1779280978)

Step 2

Select Load Snapshot

Click **Actions** , then select **Load Snapshot**.

![Actions menu showing the Load Snapshot option](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071797037/original/BhMgfjVjco6zQqf4Zmdcl2hGkKTScz0-hg.png?1779281048)

Step 3

Choose the Imported Snapshot

Select the Snapshot you imported from the available Snapshot list.

![Load Snapshot dialog showing the Snapshot selection field](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071797198/original/ZwO0VK7C06xezVfe93oI1CdtJNxIBs5tOA.png?1779281121)

Step 4

Select the Assets to Load

Select the supported Snapshot assets you want to apply to the destination sub-account.

![Snapshot asset selection screen for loading assets into a sub-account](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080791243/original/_CgHPFYFJIYjDv0n00plhjAMGv59oQ4heA.png?1789246325)

Step 5

Review Conflicts and Confirm the Load

Review any detected conflicts and choose the appropriate action for existing assets. When everything is correct, confirm the Snapshot load.

![Snapshot load confirmation screen after asset and conflict review](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155071797395/original/QFEwFaHZw2zXaPahOxnbeAk_FhbaeYlPmQ.png?1779281235)

## Frequently Asked Questions

Q: Can I rename a Snapshot while importing it?

Yes. The import pop-up lets you enter a custom Snapshot name before completing the import.

Q: Why is my imported Snapshot greyed out?

The Snapshot is still processing. Wait for it to become active instead of starting another import or trying to load it immediately.

Q: What does the shield icon mean?

The shield indicates that the Snapshot contains protected assets. Those assets can be imported, loaded, and reused within your agency, but their protected status remains attached and restricts external redistribution.

Q: Can I load imported protected assets into more than one sub-account?

Yes. Protected assets can be reused across sub-accounts within the same receiving agency. Their protected status remains attached.

Q: Can I create or refresh another Snapshot using imported protected assets?

Yes. Protected assets can be included in internal Create and Refresh workflows within your agency. Reusing them does not remove their protection.

Q: Can I share imported protected assets with another agency?

No. Protected assets remain restricted when they would leave your agency. If a mixed Snapshot is shared externally, protected assets are excluded while eligible non-protected assets can continue.

Q: What should I do if my Snapshot Share Link has expired?

Request a new Snapshot Share Link from the person or agency that originally shared the Snapshot.

Q: Does importing a Snapshot automatically load it into a sub-account?

No. Importing stores the Snapshot in your agency library. You must separately load it into the intended sub-account before its selected assets are applied.
