# Load Multiple Sub-Accounts to a Snapshot

**Source URL:** [https://help.gohighlevel.com/support/solutions/articles/155000007638-load-multiple-sub-accounts-to-a-snapshot](https://help.gohighlevel.com/support/solutions/articles/155000007638-load-multiple-sub-accounts-to-a-snapshot)  
**Category:** Account Snapshots  
**Folder:** Snapshots

---

Link/Load Multiple Sub-Accounts to a Snapshot gives agencies a faster way to apply snapshots across multiple client accounts from one central workflow in HighLevel. Instead of opening individual sub-accounts to start the load process, users can launch a single Load modal from My Account Snapshots and select multiple accounts at once. This helps agencies standardize setup, speed up onboarding, and reduce manual work when rolling out snapshot-based systems across their client base.

## **What is Link/Load Multiple Sub-Accounts to a Snapshot?**

  


Link/Load Multiple Sub-Accounts to a Snapshot expands the existing snapshot load experience by making account selection more centralized and efficient. It introduces a new modal with visibility into all agency sub-accounts, including accounts that are already linked and those that are still available. When a snapshot is loaded into an available account, HighLevel automatically links that sub-account to the snapshot as part of the same flow.

* * *

## **Key Benefits of Link/Load Multiple Sub-Accounts to a Snapshot**

  


  * **Accelerated onboarding** : Load a snapshot into multiple sub-accounts in one workflow instead of repeating the same action account by account.  
  

  * **Unified workflow** : Start from My Account Snapshots and manage rollout decisions from one central Load modal.  
  

  * **Better visibility** : Quickly see which sub-accounts are already linked to the snapshot and which ones still need it.  
  

  * **Faster standardization** : Apply your agency’s preferred setup across more client accounts with fewer manual steps.  
  

  * **Automatic linking for available accounts** : When you load a snapshot into an available sub-account, HighLevel links it during the same action.


* * *

## **Universal Account Selection**

  


Universal Account Selection makes it easier to choose where a snapshot should be loaded by placing all agency sub-accounts into a single selection experience. This helps reduce page switching and gives teams a more efficient way to manage large rollout tasks.

  


When you open the Load modal from **My Account Snapshots** , you can:

  * view agency sub-accounts in one place
  * search for specific sub-accounts by name
  * select one, several, or many accounts in the same workflow
  * start the load process without first opening each individual sub-account


This updated experience is especially helpful for agencies that manage multiple client accounts and want a faster way to apply the same snapshot across them.

## **Smart Account Tabs**

  


Smart Account Tabs improve decision-making by helping users quickly understand the current relationship between a snapshot and their sub-accounts. This saves time during onboarding, cleanup, and account standardization because users can work from filtered account groups instead of reviewing accounts one by one.

  


The Load modal includes three tabs:

  * **All** : Shows all agency sub-accounts.
  * **Linked** : Shows sub-accounts that are already linked to the selected snapshot.
  * **Available** : Shows sub-accounts that are not yet linked to the selected snapshot.  
  


These tabs make it easier to identify where the snapshot is already in use and where it still needs to be applied. For example, the Available tab can help surface accounts that were not previously connected to the snapshot.

## **How To Setup Link/Load Multiple Sub-Accounts to a Snapshot**

  


Proper setup helps agencies use the feature consistently and avoid confusion between the older single-account workflow and this new centralized experience. Following the steps below ensures the feature is enabled, the correct snapshot is selected, and target sub-accounts are chosen from the appropriate tab.

  


  1. **Open My Account Snapshots**  
  
From the Agency view, navigate to **My Account Snapshots** and locate the snapshot you want to use.  
Click **Load Updates to Sub-Account** next to the selected snapshot.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079587449/original/7XzB2TI-j6ZZPKLQOkevbgZgZQOhqKSogA.png?1787947999)  
  

  2. **Choose the correct tab**  
  
Use **All** to view every sub-account.  
Use **Linked** to view accounts already associated with the snapshot.  
Use **Available** to view accounts that are not yet linked.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069033868/original/9k5WGTceT4yGpu8wr0_NRevaNvnQen90zQ.png?1776089943)  
  

  3. **Select sub-accounts by c hecking the boxes** (Search for accounts by name if needed). Click **Load** to continue with the snapshot loading process.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079587669/original/wfv7ISUj_YqJAtELI4KObENrPGyvpiFP5A.gif?1787948252)  
  

  4. **Complete the remaining load steps**  
  
Review the snapshot items being loaded if prompted.  
Resolve any conflicts if the load flow presents conflict options.  
Confirm the action to begin loading the snapshot into the selected accounts.

## **Frequently Asked Questions**

  


**Q: What is the main difference between this feature and the older snapshot load flow?**  
The older workflow typically begins from an individual sub-account context. This feature introduces a centralized Load modal from My Account Snapshots, making it possible to select multiple sub-accounts in one place.  
  


**Q: What happens when I load a snapshot into an Available sub-account?**  
HighLevel loads the snapshot and automatically links that sub-account to the snapshot during the same process.

  


**Q: Can I select more than one sub-account at the same time?**  
Yes. The new Load modal is designed to let you select multiple sub-accounts in a single workflow.

  


**Q: Does this feature replace Push Updates?**  
A: No. This feature improves how snapshots are loaded and linked across sub-accounts. Push Updates remain a separate snapshot workflow used for ongoing update management.  
  


**Q: Where do I start this new workflow?**  
A: Start from **My Account Snapshots** in Agency view, then click **Load** next to the snapshot you want to apply.  
  


**Q: Why is this useful for agencies?**  
A: It reduces manual page-hopping, improves visibility across sub-accounts, and makes it easier to apply agency standards more efficiently.
