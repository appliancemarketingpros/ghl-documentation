Course Filters in Communities

Help Community members discover relevant learning content faster by filtering courses by Topic, Difficulty, and Language and sorting courses by Title, Newest, or Oldest.

What You'll Learn

HighLevel Communities now lets members filter courses directly from the **Learning** page using **Topic** , **Difficulty** , and **Language**. Members can also sort courses by **Title** , **Newest** , or **Oldest**.

These filtering options are powered by course metadata configured in the course builder. This guide explains how course filters work, how to configure the required values, and how members can use them inside Communities.

Course Access vs. Course Filters

Filters help members organize and discover courses they can already see. They do not grant access to restricted courses or override Community, course, offer, or enrollment permissions.

# **What is Course Filtering in Communities?**  
  


Course Filters in Communities use the Language, Difficulty, and Topic values assigned to a course to help members narrow the courses displayed in a Community's **Learning** tab.

Instead of manually browsing a growing course library, members can combine filters to focus on content that matches their preferred subject, skill level, or language. They can also sort the resulting courses to make discovery faster.

## **Key Benefits of Course Filters in Communities**  
  


Course filtering gives members a faster way to navigate learning libraries as the number and variety of available courses grows. Accurate course metadata also helps creators organize learning content consistently.

  * **Faster Course Discovery:** Members can narrow large course libraries to content relevant to their needs.
  * **More Relevant Learning:** Find courses according to Topic, Difficulty, and Language.
  * **Flexible Filtering:** Combine multiple criteria to create a more focused course list.
  * **Better Course Organization:** Creators manage the discovery metadata directly from course settings.
  * **Flexible Sorting:** Organize courses by Title, Newest, or Oldest.
  * **Quick Reset:** Members can remove active filters and return to the broader available course list.


## **Available Course Filters and Sorting Options**  
  


The Learning page uses course metadata to determine the filtering choices available to members. Assigning clear and accurate values helps members understand and discover the right learning content.

Control| Purpose  
---|---  
**Topic**|  Filters courses according to the subject or category assigned to the course.  
**Difficulty**|  Helps members find courses suited to their intended experience level.  
**Language**|  Filters courses based on the language assigned to the course.  
**Title**|  Sorts available courses according to their course titles.  
**Newest**|  Brings newer courses forward in the sorted results.  
**Oldest**|  Brings older courses forward in the sorted results.  
  
## **How Course Filters Work in Communities**  
  


Community members use the **Learning** tab to browse the courses available to them. Filters narrow that available course set according to the metadata attached to each course.

  1. The member opens the Community's **Learning** tab.
  2. The member selects one or more Topic, Difficulty, or Language values.
  3. Courses matching the selected criteria remain in the results.
  4. The member can apply a sort option to organize those results.
  5. The member can select **Reset all** to remove the active filters.

## **Course Tags and Community Filters**  
  


Community filters depend on the metadata assigned to each course. Language, Difficulty, and Topic serve as course-discovery values and determine how courses can be narrowed from the Learning page.

### **Language**

Language identifies the primary language used by the course. Assigning the correct language helps members locate content they can comfortably follow.

### **Difficulty**

Difficulty communicates the intended learner experience level. Choose the option that most accurately reflects the knowledge or skill level expected from the learner.

### **Topic**

Topic organizes courses according to their primary subject. Consistent Topic values are especially useful for Communities offering courses across several learning areas.

## **How To Setup Course Filters for Communities**  
  


Accurate course metadata ensures members can discover a course through the appropriate Community filters. Configure the course values first, save the changes, and then verify the member-facing Learning experience.

### **Step 1: Open the Course**

Course discovery settings are managed from the individual course configuration, so begin with the course you want members to find through Community filters.

  1. Go to **Memberships → Courses**.
  2. Open the course you want to configure.
  3. Select **Settings**.


### **Step 2: Find Course Tags**

The Course tags area contains the discovery metadata used by the course-library filtering experience.

  * Language
  * Difficulty
  * Topic


### **Step 3: Assign the Course Values**

Choose values that accurately represent the course. Consistent metadata makes filtering more useful and avoids placing content under misleading criteria.

  1. Select the appropriate **Language**.
  2. Select the appropriate **Difficulty**.
  3. Select the appropriate **Topic**.
  4. Review the values before saving.


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080661435/original/afktLBTT1aJ1q6sEUybaGkJcrnlBWDlDcw.png?1789102244)

### **Step 4: Save the Course**

Saving applies the selected discovery metadata to the course. Use consistent values across related courses whenever possible so members receive predictable filtering results.

### **Step 5: Verify the Course in the Community**

Testing from the member-facing Learning page confirms the course appears under the intended filters and remains subject to the correct course-access rules.

  1. Open the applicable Community.
  2. Select **Learning**.
  3. Confirm the course is visible to a member who should have access.
  4. Apply the applicable Topic, Difficulty, or Language filter.
  5. Confirm the course appears in the expected results.
  6. Test the available sorting options as needed.


## **Filtering Courses as a Community Member**  
  


Filters give members control over how they browse available learning content without changing enrollment or permissions. Multiple criteria can be used together to progressively narrow the course list.

  1. Open the applicable Community.
  2. Click **Learning**.
  3. Choose one or more **Topic** , **Difficulty** , or **Language** values.
  4. Review the matching courses.
  5. Use **Sort** to organize the results by Title, Newest, or Oldest.
  6. Select **Reset all** when you want to remove the active filters.


## **Troubleshooting Course Filters in Communities**  
  


Most filtering issues can be traced to missing course metadata, course-access restrictions, or active filter combinations. Verify those areas before changing the course itself.

Issue| What to Check  
---|---  
**A filter does not show the expected course**|  Open the course Settings and confirm the correct Language, Difficulty, or Topic value is assigned and saved.  
**The member cannot see the course at all**|  Check the course's Community visibility and access configuration. Filters do not override access restrictions.  
**Too few courses are displayed**|  Review all active filters. Combining multiple criteria can substantially narrow the results.  
**The course appears under the wrong filter**|  Verify the metadata assigned to the course and correct any inaccurate values.  
**The member wants to see all courses again**|  Select Reset all to remove the active filters.  
**A newly configured value is not reflected**|  Save the course, refresh the Community Learning page, and confirm you are testing the correct course and Community.  
  
## **Frequently Asked Questions**  
  


Q: Which filters are available for Community courses?

Members can filter available courses by Topic, Difficulty, and Language.

Q: How can members sort Community courses?

Members can use the available Title, Newest, and Oldest sorting options.

Q: Can members use more than one filter?

Yes. Members can combine available filter criteria to narrow the course list further.

Q: Where are the filter values configured?

Course creators assign Language, Difficulty, and Topic values from the individual course's Settings area.

Q: Do course filters change who can access a course?

No. Filters organize courses that are already available to the member. Course access and visibility are controlled separately.

Q: What happens if a course does not have one of the filter values assigned?

The course may not appear when a member filters specifically for that criterion. Assign accurate metadata when you want the course to participate in that filtering experience.

Q: Can members clear all selected filters?

Yes. Select Reset all to remove the active filters and return to the broader available course list.
