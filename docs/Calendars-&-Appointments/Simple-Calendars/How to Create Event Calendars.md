# **What are Event Calendars?**

  


Event Calendars in HighLevel are a calendar type designed for scheduling events that do not require a host or user association. Instead of assigning meetings to a specific team member, this calendar type allows bookings to be managed at the calendar level, which makes it a strong fit for public or shared event scheduling. This is especially helpful when availability is based on the event itself rather than an individual user's connected calendar, and it also makes Event Calendars one of the most straightforward calendar types to set up in HighLevel.

* * *

## **Key Benefits of Event Calendars**

  


  * **No Host Required** : Create bookable schedules without assigning meetings to a specific user.  
  


  * **Simple to launch** : Set up an event-based booking calendar without needing to assign a user or build the calendar around a staff member's availability.

  


  * **Simple Booking Experience** : Share a booking link or embed code so attendees can register through a dedicated scheduling page.  
  


  * **Flexible Meeting Location Options** : Add a physical location or paste a static virtual meeting link into the meeting location field.  
  


  * **Focused External Sync** : Sync bookings only with the external calendar selected for that Event Calendar.


* * *

## **Important Differences for Event Calendars**

  


Event Calendars behave differently from personal, team, and other calendar types in HighLevel. Understanding these differences before setup helps prevent sync issues, unsupported meeting-link expectations, and confusion around calendar conflicts.

  


  * Event Calendars do not have users, so meetings cannot be assigned to a user.  
  


  * Because no user is assigned, dynamic meeting link tools are not supported (such as Zoom, Google Meet, and Microsoft Teams)  
  


  * To use online meetings, copy a static conferencing link from your meeting platform and paste it into the meeting location.  
  


  * Because no user is assigned, meetings do not sync to a user's calendar from **Calendar Settings > Connections**.  
  


  * Conflict calendars added under **Calendar Settings > Connections** are not considered for Event Calendars.  
  


  * Meetings sync only to the calendar selected under **External Sync** for that Event Calendar.  
  


  * Events are fetched from and pushed only to the selected external calendar.  
  


  * Only one Google Calendar can be connected using External Sync.


* * *

## **When to Use Event Calendars**

  


Choosing the right calendar type helps ensure your booking flow matches the experience you want to offer. Event Calendars are best when the event itself is the focus and bookings do not need to be tied to a specific staff member.

  


  * Use Event Calendars for conferences, expos, seminars, workshops, public sessions, and other shared event bookings.  
  


  * Use Event Calendars when you do not want to assign meetings to a user.  
  


  * Use Event Calendars when you want a faster, simpler setup that does not depend on a team member's availability settings.  
  


  * Do not use Event Calendars when bookings need to rotate between users, depends on multiple staff calendars or depends on staff calendar availability.

## **How To Setup Event Calendars**

  


  1. In your sub-account, go to **Calendars** from the left-hand navigation menu. In the top navigation bar, click **Calendar Settings**.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066923565/original/Lq8oVLYqaGvbtciBIephSghs2sfYhxPjMg.png?1773433724)  
  

  2. On the Calendar Settings page, click **\+ New Calendar** in the top-right corner.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066923572/original/CEI2JkUFGjfYfFON7YMni8e6sNDP-6YtFA.png?1773433756)  
  

  3. In the calendar type pop-up, open the drop-down for more calendar types and select **Event Calendar.**  
  
**![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066923583/original/4obFphkm_39dIwqPteQPwAOqEtDuPApvHA.png?1773433785)**  

  4. Enter a**Calendar Name** , optionally add a **Description** for the calendar and Customize the **Custom URL** if you want to change the booking widget link.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066923696/original/mSXrFnm34GO7Unpz5jLkuO0uilg03YaXoQ.png?1773433965)  
  

  5. Set the **Meeting Duration** and configure **Availability** by selecting the days and times the event can be booked.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066923702/original/_oIFKQOmT3m7HvpAU9C7rn78tUhPavWXnQ.png?1773434000)  
  

  6. Add the **Meeting Location**. For in-person events, enter the physical location. For virtual events, paste a static conferencing link.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066923724/original/tpu--2kWhI-01Mk6rc4kfIlGnBSTswTwFA.png?1773434031)  
  

  7. Click **Advanced Settings** if you need to configure additional options.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066923663/original/9REZNu6BgyLGqZe1KyBoQjHBt0X-LlliUg.png?1773433913)  
  

  8. Click **Confirm** to create the Event Calendar. After the success message appears, copy the booking link or embed code as needed.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155066923746/original/vikux9-ODk8fteIRLR9SZpmL0sBukuQ-yw.png?1773434074)

## **Frequently Asked Questions**

  


**Q: Can Event Calendars use virtual locations such as Zoom, Google Meet, or Microsoft Teams automatically?**  
Yes. Dynamic meeting links are not supported because Event Calendars do not have an assigned user but a static link can be use.

  


**Q: Where do Event Calendar bookings sync?**  
Bookings sync only to the external calendar selected for that Event Calendar.

  


**Q: Can Event Calendars sync with more than one Google Calendar?**  
No. Only one Google Calendar can be connected using External Sync.
