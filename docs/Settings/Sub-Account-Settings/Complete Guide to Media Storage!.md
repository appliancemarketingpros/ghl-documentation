To access Media Storage, go to the **left sidebar** of your dashboard and click **Media Storage**.

## **Upload Files**

  


### **Upload Individual Files**

  


Drag files from your computer directly into the Media Storage interface to upload them.

For supported file types, upload limits, browser compatibility, and advanced Media Storage behavior, see **Media Storage File Types, Limits & Advanced Features**.

  


### **Track Upload Progress**

  


When you upload files to Media Storage, the upload panel shows progress in real time. The header shows the number of items uploading, the transferred size, and the overall upload percentage.

Each file shows its upload percentage and transferred size compared with its total file size. When a file finishes uploading, a green checkmark marks it as complete.

  


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078463018/original/1w229jac7jaWmhus7TiOtfxT0yF9uwWtDw.png?1786718595)

  


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155078463052/original/VhHTXkGwMLWNsKeqpJsxAR-8E7mnn_NX5Q.png?1786718610)

  


### **Upload a Folder**

  


You can upload an entire folder to Media Storage while keeping its folder structure.

During the upload, progress appears in a folder-based view so you can track nested folders and files. A toast notification also shows how many items were skipped.  
  


Folder uploads support up to **3 levels of nested folders** and up to **1,000 files per upload**.

  


To upload a folder:

  


  1. Click **Upload**.  
  

  2. Select **Upload Folder**.


  


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073303793/original/_aXXVBB2S2AjWZKtcjMN7t4KTPHnH2VkBg.png?1781032490)

## **Organize and Find Media**

  


### **Search Media Storage**

  


Use the Media Storage search bar to find files and folders across your entire media library.

Search results include matching items from the main Media Storage level and from folders and subfolders at any depth.

Search remains global even when you start searching from inside a folder. The same search behavior is available in List View.

  


### **Find a File's Location**

  


Hover over a file in the search results to view its folder path. The folder path shows where the file is stored in Media Storage.

  


### **Open the Containing Folder**

  


To go directly to a file's location:  
  


  1. Find the file using the Media Storage search bar.  
  

  2. Click the **three-dot** menu for the file.  
  

  3. Select **Open containing folder**.  
  


Media Storage opens the folder containing the file and clears the search field.

  


### **Sort Media**

  


Sort your media using the following options:

  * **Sort by Name:** A to Z or Z to A  
  

  * **Sort by Size:** Smallest First or Largest First  
  

  * **Sort by Modified Date:** Newest First or Oldest First


  


### **Grid and List View**

  


Toggle between **Grid View** and **List View** based on how you want to browse your files.  
  


  * **Orientation Badge in Grid View:** Images display a badge showing **Landscape** , **Portrait** , or **Square**.  
  

  * **Pixel Dimensions in List View:** Width × Height values appear next to image names so you can review image dimensions before using a file.


    
    
    **Note:** Older uploaded images may not immediately display dimensions due to background processing delays.

## **Preview and Insert Media**

  


When Media Storage is used within supported HighLevel products, such as the website or funnel builder, you can preview and insert files without leaving your workflow.

  


### **Open a File Preview**

  


Open the **three-dot** menu for a file and select **Preview** to review the file before using it.

  


### **Navigate Between Files**

  


Use the arrow buttons in Preview, or press the left and right arrow keys on your keyboard, to move between images and videos without closing each file.

  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079729648/original/KYP5P0KDd0X285ADlMcxdh3ZxcVMoVeM6Q.gif?1788193438)  
  


### **Interactive Image Preview Controls**

  


When you preview an image in **Media Storage** , you can inspect image details without downloading the file or leaving Media Storage.  
  


  * **Zoom an image:** Zoom from 100% to 400% using the toolbar, mouse wheel or trackpad, pinch gestures, or keyboard controls. Zoom follows your cursor so you can focus on a specific part of the image.  
  

  * **Pan while zoomed:** Click and drag the image to inspect different areas while zoomed. The image remains within the Preview area.  
  

  * **View an image in fullscreen:** Expand the image to fullscreen for a larger view. While fullscreen is active, press `Esc` to exit fullscreen and return to Preview.  
  

  * **Move the control bar:** Drag the floating control bar to reposition it. You can also use the arrow keys to move it.  
  

  * **Start each Preview with a clean state:** Zoom level, pan position, control-bar placement, and fullscreen state reset when you switch files or close Preview.  
  


These interactive controls apply to image previews. Other file types continue to use their existing Preview behavior.

Image Preview supports keyboard navigation and screen readers and respects the user's **Reduce Motion** preference.

  


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155079725261/original/dhGQeyIpQfSxqneQNchM03vz2n1ya_qpNw.gif?1788190614)

  


### **Insert Media**

  


  * Use the **Insert Media** button to select and insert a single file.  
  

  * Insert files directly from the Preview screen.

## **Manage Files and Folders**

  


### **Quick Actions**

  


Access file options using the right-click menu or hover-over quick action buttons.

Available actions include:

  * Rename  
  

  * Delete  
  

  * Move to Folder  
  

  * Preview  
  

  * Insert


  


### **Collapse or Expand the Folders Section**

  


If you have a large folder structure, collapse the **Folders** section to reduce clutter and focus on your files.

Click the arrow next to Folders to collapse the folder list. Click it again to expand the list.

  


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155064213379/original/G4GeHcJHvWE6FQh7TbvL_lxFwkvmKIpD3g.png?1770233460)

  


### **Move Entire Folders**

  


You can move entire folders with their contents, including nested files and subfolders.

To move a folder:

  1. Click the **three-dot (⋮)** menu next to the folder and select **Move to Folder**.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062681158/original/brQ-banAB_56UTODCRgje7xoH4QnU7-xzw.jpeg?1768421594)  
  

  2. Choose an existing folder or create a new one.  
  

  3. Confirm the move.


    
    
    **Note:** Moving a folder keeps its nested subfolders intact.

  
  


### **Download a Folder as a ZIP**

  


You can download an entire folder as a single ZIP file. Folder downloads preserve the original folder structure, including nested subfolders.

Folder downloads require sufficient local disk space in the browser environment.  
  


To download a folder:  
  


  1. Click the **three-dot** icon next to the folder and click **Select**.  
  

  2. Ensure the folder is selected and select any additional folders you want to download.  
  

  3. Click **Download** to save the selection as a ZIP file.


  


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155073303954/original/ElMRRds-_Gp0BBmrO942E-t3MdSe_YZk0g.png?1781032766)

## **Trash and File Recovery**

  


Deleted media files move to **Trash** , where they remain for **30 days** before permanent removal.  
  


  1. Click the **three-dot** menu at the top right and select **Trash**.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062681193/original/XNTvb1LKzxjgQsuL9BM67N6fYXpyt8KMRA.jpeg?1768421700)  
  

  2. Choose a file to **Restore** or **Delete Permanently**.  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155062681195/original/vrmNhmNMZex7hYAbEnDI5yLl6dSCU1qZwA.jpeg?1768421711)  
  


    
    
    **Important:** Files are non-recoverable after 30 days.
    
    Trash access is location-wide. Any user logged into the same location can view and restore items in Trash, regardless of who moved them there.

## **Frequently Asked Questions**

  


**Q: Can I use both Grid View and List View?**  
Yes. Grid View displays image orientation badges, while List View displays image pixel dimensions.

  


**Q: What sorting options are available?**  
You can sort by name, size, and modified date using ascending or descending order.

  


**Q: What happens to deleted files?**  
Deleted files move to Trash for 30 days. Users in the same location can view and restore trashed items or permanently delete them. After 30 days, files are removed and cannot be recovered.
