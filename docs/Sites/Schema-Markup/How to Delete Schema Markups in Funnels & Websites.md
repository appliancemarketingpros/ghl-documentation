# **What is Schema Markup Deletion?**

  


Schema markup deletion allows users to remove structured data (JSON-LD) from a page within the Website or Funnel Builder. This is important when schemas become outdated, incorrectly configured, or no longer relevant to your SEO goals. By enabling direct removal, HighLevel ensures users can maintain accurate search engine signals without needing to rebuild pages.

* * *

## **Key Benefits of Schema Markup Deletion Flow**

  


  * **Flexible Deletion Methods** : Remove schema using Form View, JSON View, or AI chat depending on your workflow.  
  


  * **Granular Control** : Delete a single schema or remove all schemas from a page.  
  


  * **AI-Powered Management** : Use conversational prompts to manage schema without manual editing.  
  


  * **Built-in Safeguards** : Confirmation prompts prevent accidental deletions.  
  


  * **Recovery Capability** : Restore deleted schema using version history.  
  


  * **Universal Availability** : Works across both Website Builder and Funnel Builder pages.

## **How to Delete Schemas in Form View**

  


Form View provides a visual interface for managing schemas, making it easy to remove specific schema types without editing raw code.

  


  1. Go to **Sites** > Open **Website** or **Funnel** **Builder.**  
  


  2. Click **Edit Page.**  
  
**![](https://jumpshare.com/share/nMol3PmLQbmFoM67FH25+/GIF+Recording+2026-04-23+at+18.57.32.gif)**  
  


  3. Navigate to**SEO & AI search optimization** → **Schema Markup.**  
  
**![](https://jumpshare.com/share/ZMCUPnrxNFXYhOiz7v9J+/Screen+Shot+2026-04-23+at+18.58.56.png)**  
  


  4. Open the**schema** **editor** (**Form** **View**).  
  


  5. In the left panel, locate the **schema** **list**.  
  


  6. Click the **three-dot menu** next to a schema.  
  


  7. Select **Delete** to remove an individual schema.  
  


  8. Click on **Yes, Delete** from the **Delete this Category** popup.  
  
![](https://jumpshare.com/share/RfWZ82f7MZmLqfBGmN3n+/GIF+Recording+2026-04-23+at+19.03.43.gif)  
  


  9. **To delete all schemas:**  
  


     1. Delete all schemas from the list.  
  


     2. Click **Validate & Save.**  
  


     3. Confirm the prompt: **"Delete all schema markup?"**  
  


     4. Click **Yes, Delete.**


  


![](https://jumpshare.com/share/KG16bXPVydmKo8zXDzl5+/GIF+Recording+2026-04-23+at+19.07.34.gif)

## **How to Delete Schemas in JSON View**

  


JSON View allows direct control over schema markup by editing the raw JSON-LD code, which is useful for advanced users.

  


  1. Go to **Sites** > Open **Website** or **Funnel** **Builder.**  
  


  2. Click **Edit Page.**  
  
**![](https://jumpshare.com/share/nMol3PmLQbmFoM67FH25+/GIF+Recording+2026-04-23+at+18.57.32.gif)**  
  


  3. Navigate to**SEO & AI search optimization** → **Schema Markup.**  
  
**![](https://jumpshare.com/share/ZMCUPnrxNFXYhOiz7v9J+/Screen+Shot+2026-04-23+at+18.58.56.png)**  
  


  4. Open the**schema** **editor** and switch to **JSON View.**  
  


  5. Remove all JSON-LD code from the editor.  
  


  6. Click **Validate & Save.**  
  


  7. Confirm the deletion prompt.  
  
![](https://jumpshare.com/share/8TxS2GwqMRsf7Sy3ORFL+/GIF+Recording+2026-04-23+at+19.13.21.gif)

## **How to Delete Schemas Using AI Chat**

  


AI-powered schema management enables quick and intuitive deletion using natural language prompts, reducing manual effort.

  


  1. Open **Ask AI** , **Funnel AI** , or **Schema Markup AI.**  
  


  2. Enter a prompt such as:  
  


     * "**Remove all schema markup from this page"**  
**  
**

     * **"Delete the Organization schema"**  
**  
**

  3. AI reviews the existing schema and performs the deletion.  
  


  4. A confirmation message appears with an option to view schema markup.


  


![](https://jumpshare.com/share/9B5r7KRmQvUlGMI6ac1Q+/GIF+Recording+2026-04-23+at+19.25.12.gif)

## **Recovery via Version History**

  


Version history provides a safety net by allowing previously deleted schema to be restored without rebuilding it from scratch.

  


  1. Open the page in the builder.  
  


  2. Access **Version History** from the toolbar.  
  


  3. **Restore** a version that contains the schema.  


  


![](https://jumpshare.com/share/cWHsDN51Xi9ZNItLRJEg+/GIF+Recording+2026-04-23+at+19.32.54.gif)

## **Frequently Asked Questions**

  


**Q: Can I undo schema deletion?**  
Deletion cannot be undone directly, but you can recover schema using version history.

  


**Q: Does deleting schema affect other pages?**  
No, schema deletion is page-specific.

  


**Q: What happens if I delete only part of the JSON?**  
Partial edits may cause validation errors. Ensure all schema code is removed for full deletion.

  


**Q: Do I need to republish the page after deleting schema?**  
Yes, changes go live only after publishing.

  


**Q: Can AI delete multiple schemas at once?**  
Yes, AI can remove individual or all schemas based on your prompt.

  


**Q: Will schema changes appear immediately?**  
Changes appear in preview after saving but require publishing to go live.
