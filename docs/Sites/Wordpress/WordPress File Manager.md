## What is the WordPress File Manager?

The WordPress File Manager is a built-in tool that provides direct access to your WordPress site's filesystem from within HighLevel. It eliminates the need for external FTP clients or cPanel access by offering a comprehensive interface for managing files and folders.

With the File Manager, you can browse your site's directory structure, upload and download files, edit file contents, create and delete folders, manage archives, and update file permissions—all from a single location. This integrated approach streamlines WordPress site maintenance and gives you faster access to critical file operations.

The File Manager supports essential workflows like theme customization, plugin modifications, troubleshooting, and content management, making it an indispensable tool for WordPress site administrators.

2

## Key Benefits

The WordPress File Manager simplifies site administration by consolidating file operations into an intuitive, accessible interface. Key advantages include:

**Unified File Access** — Manage your entire WordPress filesystem from a single interface without switching between FTP clients, cPanel, or SSH terminals.

**Faster Workflow** — Upload, edit, and organize files instantly with search, filtering, sorting, and pagination to navigate large directory structures efficiently.

**Safe Editing** — Preview file contents before making changes and benefit from conflict-safe protection that helps prevent accidental overwrites of newer file versions.

**Complete File Operations** — Create, delete, compress, extract, and manage permissions for files and folders without external tools.

**Streamlined Maintenance** — Troubleshoot issues, customize themes, and modify plugins directly through the File Manager, reducing time spent switching between platforms.

## File Manager Capabilities

The WordPress File Manager provides comprehensive file and folder management tools designed for efficient WordPress site administration. Each capability is built to streamline common workflows and reduce dependency on external applications.

Browse Files & Folders

Navigate Your Site's Filesystem

Quickly explore your WordPress directory structure with powerful navigation tools. Use the built-in search to locate specific files, apply filters to narrow results, sort files by name or date, and navigate large directories with pagination. This makes it easy to find and access any file on your site.

Upload & Download

Transfer Files To and From Your Site

Upload files in supported formats directly to any folder on your WordPress site. Download files whenever needed for backup, editing offline, or sharing with collaborators. This eliminates the need for FTP clients and simplifies file transfers.

Edit Files

Preview and Modify File Contents Safely

Preview file contents before making changes to ensure you're editing the correct file. Edit and save files directly in the File Manager with conflict-safe protection that helps prevent overwriting newer updates made by other users or processes. This safeguard reduces the risk of accidental data loss.

File & Folder Management

Perform Common File Operations

Execute essential file and folder operations with ease:

  * Create new files and folders to organize your site structure
  * Delete unnecessary files and folders to free up space
  * Compress files and folders into archive formats for backup or distribution
  * Extract archive files to restore backups or unpack plugins and themes


File Permissions

Update Permissions (chmod) Where Supported

Modify file and folder permissions to control access and security settings. Where supported by your hosting environment, you can update chmod values to ensure proper read, write, and execute permissions for WordPress core files, themes, plugins, and uploads.

Centralized Control

Manage Your WordPress Files Without Leaving HighLevel

The WordPress File Manager brings FTP-level control directly into your workflow, eliminating the need for external tools and simplifying site administration.

## How to Use the WordPress File Manager

Follow these steps to access and use the WordPress File Manager to manage your site's files and folders.

Step 1

Access the File Manager

Navigate to your WordPress management section within HighLevel. Locate and click on the File Manager option to open the file browser interface.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077593453/original/j_uVoXrIQv8bGGHqwUk12oE9wIGEIOfwbg.png?1785848450)

Step 2

Browse and Search Your Files

Use the file browser to navigate through your site's directory structure. Click on folders to expand them. Use the search bar to find specific files, apply filters to narrow results, or sort files by name or modification date. Pagination controls help you navigate large directories efficiently.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077594797/original/i8ypnHL9yGbWrmLAeag2F2y1WwezVF0krQ.gif?1785849004)

Step 3

Upload or Download Files

To upload files:

  * Navigate to the target folder
  * Click the Upload button
  * Select files from your computer in supported formats  
  


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077594180/original/6kQeGODNv8xAvJ_wJfyU5kqmuYA-OAD-Dw.png?1785848781)  
  


To download files:

  * Select the file or folder you want to download
  * Click the Download button
  * The file will be saved to your local device  
  


![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077594651/original/hFw_9Wa04Pi-OB5MuERkNBhirfdOgEFyIQ.png?1785848937)

Step 4

Edit Files Safely

To edit a file:

  1. Select the file you want to edit  
  

  2. Click the Edit button to view file contents  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077595045/original/qPEZsIA0qv3JQH0UQaORDi0SBSglmVIBkA.png?1785849099)  
  

  3. Make your changes in the editor  
  

  4. Click Save to apply changes  
  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155077595173/original/5U837Pxy7NxDpUyHD46zXM8ZdBAnQIWPJA.png?1785849134)  
  


The File Manager includes conflict-safe protection that alerts you if the file has been modified by another user or process since you opened it, helping prevent accidental overwrites.

Pro Tip

Always preview file contents before editing critical files like wp-config.php or .htaccess to ensure you're modifying the correct file and understand its current state.

Step 5

Manage Files and Folders

Perform common file operations using the File Manager toolbar and context menus:

  * **Create:** Click the New File or New Folder button to create new items in the current directory
  * **Delete:** Select files or folders and click the Delete button to remove them from your site
  * **Compress:** Select files or folders and click the Compress button to create an archive (e.g., .zip)
  * **Extract:** Select an archive file and click the Extract button to unpack its contents


[Screenshot: File Manager toolbar showing Create, Delete, Compress, and Extract options]

Step 6

Update File Permissions (chmod)

To modify file or folder permissions:

  1. Select the file or folder
  2. Click the Permissions or Properties button
  3. Adjust the permission settings (read, write, execute) for owner, group, and others
  4. Click Save to apply the new permissions


Note that permission management depends on your hosting environment's support for chmod operations. If this feature is unavailable, consult your hosting provider.

Warning

Incorrect file permissions can compromise site security or break functionality. Always verify recommended permission settings for WordPress core files, themes, and plugins before making changes.

## Frequently Asked Questions

Q: Do I need FTP credentials to use the WordPress File Manager?

No, the WordPress File Manager operates directly through HighLevel and does not require FTP credentials. It provides built-in access to your site's filesystem without needing external FTP clients or cPanel.

Q: What file formats can I upload through the File Manager?

The File Manager supports uploading files in all standard formats commonly used in WordPress environments, including images, documents, scripts, stylesheets, and archive files. If a specific format is restricted, the File Manager will notify you during the upload process.

Q: What happens if I try to save a file that has been modified by someone else?

The File Manager includes conflict-safe protection that detects when a file has been modified since you opened it. If a conflict is detected, you'll receive a notification allowing you to review changes, merge edits, or cancel your save to prevent accidental overwrites.

Q: Can I compress and extract files using the File Manager?

Yes, the File Manager allows you to compress files and folders into archive formats (such as .zip) and extract archive files to restore backups or unpack plugins, themes, and other content. Select the files or folders you want to compress or the archive file you want to extract, then use the Compress or Extract buttons in the toolbar.

Q: How do I update file permissions if the option is unavailable?

File permission management (chmod) depends on your hosting environment's support. If the permissions option is unavailable in the File Manager, you may need to use your hosting provider's control panel or contact their support team to modify file and folder permissions.

Q: Can I use the File Manager to edit theme or plugin files?

Yes, the File Manager allows you to browse, preview, and edit theme and plugin files. Always back up files before making changes, and test modifications on a staging site when possible to avoid disrupting your live site.

Q: Is there a file size limit for uploads?

File upload size limits are determined by your hosting environment's PHP settings. If you encounter upload size restrictions, you may need to adjust your hosting configuration or contact your hosting provider to increase the maximum upload size.

Q: Can I delete multiple files or folders at once?

Yes, you can select multiple files or folders using checkboxes in the File Manager interface, then click the Delete button to remove all selected items at once. Use caution when deleting multiple items to avoid accidentally removing important files.
