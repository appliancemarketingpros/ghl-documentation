# **What is Universal Content Customization for AI Pages?**

  


Universal Content Customization lets you edit supported content on AI-generated WordPress pages directly from the HighLevel preview. Instead of switching to Elementor whenever you need to change copy or replace an image, you can make many common updates from the **Customizations** panel.

  


Supported editable elements include:

  * Headings

  * Paragraphs

  * Buttons

  * Icon Box titles

  * Icon Box descriptions

  * Images


  


You can select a supported element, change the content manually, use AI-assisted editing options, and save the result. Saved updates are reflected on the WordPress page.
    
    
    **Important:** Universal Content Customization requires **LeadConnector WordPress Plugin v4.0.4 or later**.

  


* * *

## **Key Benefits of Universal Content Customization**

  


Editing content directly from the page preview reduces the number of tools you need for simple page updates. You can make faster changes while keeping the generated page connected to the WordPress and Elementor workflow.

  


  * **Edit more page content:** Update supported headings, paragraphs, buttons, Icon Boxes, and images across the generated page.  
  


  * **Reduce context switching:** Make routine changes without opening Elementor.  
  


  * **Use AI-assisted writing tools:** Rephrase, shorten, elaborate, or change the tone of selected text.  
  


  * **Regenerate individual images:** Replace supported AI-generated images without rebuilding the entire page.  
  


  * **Preview before saving:** Review changes before applying them to the page.  
  


  * **Keep Elementor available:** Continue using Elementor when you need deeper layout or design control.


* * *

## **Requirements**

  


The correct WordPress integration version is required for Universal Content Customization to work as expected. Checking the plugin version first can help prevent missing editing controls or unsupported behavior.

You need:

  * An AI-generated WordPress page in HighLevel.  
  


  * **LeadConnector WordPress Plugin v4.0.4 or later**.


  
For newly provisioned WordPress sites hosted through HighLevel, the LeadConnector plugin is installed automatically. You can also review the plugin connection status from the WordPress area in HighLevel.

If you need to download or update the plugin manually, the latest versions are available through the LeadConnector WordPress Plugin Hub.

## **Supported Content Elements**

  


Universal Content Customization expands editing beyond a small number of predefined page sections. Selecting supported content directly from the preview makes it easier to update copy wherever it appears on the AI-generated page.

  


Supported elements include:

  * **Headings:** Change titles and section headings.  
  


  * **Paragraphs:** Update longer descriptions and body copy.  
  


  * **Buttons:** Change supported button content.  
  


  * **Icon Box titles:** Edit the heading associated with an Icon Box.  
  


  * **Icon Box descriptions:** Update the descriptive text below an Icon Box.  
  


  * **Images:** Replace or regenerate supported images.


  


Not every Elementor element should be assumed to support direct customization. If an element cannot be selected from the HighLevel preview, use Elementor for additional editing.

## **Editing Text Directly from the Page Preview**

  


Direct text editing lets you correct wording, update business information, or refine generated copy without leaving the page preview. Selecting the text opens its current content in the **Customizations** panel so you can make the change in context.

  


To edit supported text:

  1. Open the AI-generated WordPress page preview.  
  


  2. Hover over the text you want to change.  
  


  3. Click the supported element.  
  


  4. Review the selected text in the **Customizations** panel.  
  


  5. Replace or edit the text.  
  


  6. Preview the change if needed.  
  


  7. Click **Save Changes** when you are satisfied.

## **Using AI-Assisted Text Editing**

  


AI-assisted editing can help you improve existing copy without writing a replacement from scratch. The available tools let you adjust the length, wording, or style of selected content while keeping the original page structure.

  


Available options include:

  * **Rephrase:** Rewrite the selected content using different wording.  
  


  * **Shorten:** Create a more concise version.  
  


  * **Elaborate:** Add more detail to the existing text.  
  


  * **Change Tone:** Rewrite the content with a different communication style.


  


You can review the generated result before saving it to the page.

## **Customizing Images**

  


Image customization lets you update supported AI-generated visuals without regenerating the entire page. This is useful when the page structure works well but a particular image does not match your business or message.

The AI-Powered WordPress Page Builder supports targeted image regeneration, allowing individual AI-generated images to be replaced while keeping the rest of the page intact. 

  


When an image supports customization:

  1. Hover over the image.  
  


  2. Select the image to open its customization options.  
  


  3. Enter or adjust the image-generation instructions.  
  


  4. Generate a replacement.  
  


  5. Review the new image.  
  


  6. Apply and save the change.


* * *

## **Previewing and Saving Changes**

  


Previewing before saving helps you confirm that the new copy or image works with the surrounding design. Saving then applies the selected customization to the WordPress page.

  


Use the available controls to:

  * **Preview Changes:** Review the updated page before finalizing your edits.  
  


  * **Save Changes:** Apply the customization to the page.  
  


  * **Edit on Elementor:** Open the page in Elementor when you need additional design or layout controls.


  


The existing AI-Powered WordPress Page Builder workflow supports further editing in Elementor after the page has been generated.

* * *

## **When to Use Elementor**

  


Universal Content Customization is designed for faster routine content updates, while Elementor remains useful for deeper page editing. Knowing when to use each option can help you avoid unnecessary switching while still retaining full design flexibility.

  


Use the HighLevel page preview for supported tasks such as:

  * Updating text

  * Refining generated copy

  * Changing tone

  * Regenerating supported images


  


Use **Edit on Elementor** when you need more advanced changes, such as:

  * Restructuring page layouts

  * Working with unsupported Elementor elements

  * Making detailed design adjustments

  * Changing advanced styling or widget settings

## **How To Customize an AI-Generated WordPress Page**

  


Following the customization workflow helps ensure that you select a supported element, review the result, and save the change correctly. You can repeat the process for different text and image elements across the page.

###   


### **Step 1: Open the AI-Generated Page**

  1. Go to **Sites > WordPress > All Sites**.  
  


  2. Open the appropriate WordPress site.  
  


  3. Go to **Pages**.  
  


  4. Open the AI-generated page you want to customize.


  


The existing AI-Powered WordPress Page Builder documentation uses the WordPress Pages area for creating and managing AI-generated pages.

###   


### **Step 2: Select a Supported Element**

  1. Move your cursor over the page preview.  
  


  2. Hover over the text or image you want to change.  
  


  3. Click the supported element.  
  


  4. The **Customizations** panel opens on the right.


  


****![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080004243/original/w6eVcdzdgegD7jzjP8PF_TFa1xZNTiUHPA.jpeg?1788436126)****

###   


### **Step 3: Edit the Content**

For text:

  1. Update the content manually, or select an AI-assisted option.  
  


  2. Use **Rephrase** , **Shorten** , or **Elaborate** if you want HighLevel to generate a revised version.  
  


  3. Use **Change Tone** when you want to adjust how the content sounds.  
  


  4. Review the result.


**![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155080003791/original/5CTyuUvyDkPSkqIYS4O2RbihMA51PYvgDA.png?1788435859)**

###   


### **Step 4: Customize an Image if Needed**

For a supported image:

  1. Select the image.  
  


  2. Open the available customization or regeneration controls.  
  


  3. Provide updated image instructions.  
  


  4. Generate the replacement.  
  


  5. Review the new image before applying it.


###   


### **Step 5: Preview the Changes**

Click **Preview Changes** to review how the edits appear on the page.

Check:

  * Text accuracy

  * Tone

  * Spacing

  * Image fit

  * Overall page consistency


###   


### **Step 6: Save the Changes**

Click **Save Changes** when the page looks correct.

Your saved updates are applied to the WordPress page.

###   


### **Step 7: Use Elementor for Additional Changes**

If you need editing options that are not available in the HighLevel preview, click **Edit on Elementor** and continue customizing the page there.

## **Frequently Asked Questions**

  


**Q: Can I edit every element on an AI-generated WordPress page?**  
A: No. Universal Content Customization applies to supported elements. If an element cannot be selected or customized from the HighLevel preview, use Elementor for additional editing.

  


**Q: Do I still need Elementor?**  
A: Not for many routine content changes. You can update supported text and images directly in HighLevel, but Elementor remains available for advanced layout, styling, and unsupported elements.

  


**Q: What plugin version do I need?**  
A: Universal Content Customization requires **LeadConnector WordPress Plugin v4.0.4 or later**.

  


**Q: Why do I not see the customization controls?**

A: Confirm that you are working with a supported AI-generated WordPress page and that the LeadConnector WordPress Plugin is on the required version or later.

  


**Q: Can I change the tone of generated content?**  
A: Yes. Supported text can use tone options such as Professional, Friendly, Compelling, and Confident.

  


**Q: Can I regenerate only one image?**

A: Yes. Supported AI-generated images can be regenerated individually without rebuilding the entire page.

  


**Q: What is the difference between Preview Changes and Save Changes?**  
A: Preview lets you review the updated page before finalizing your edits, while Save Changes applies your customization.

  


**Q: Can I continue editing the page in Elementor afterward?**  
A: Yes. The generated WordPress page can still be opened and edited in Elementor.
